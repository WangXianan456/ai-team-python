# AI Team Python

Python-stack specialization layer for the shared AI-team operating model.

## Intended Contents

- Python role overlays (FastAPI/Django/Flask profiles)
- Python security/testing/build conventions
- Python-specific skill packs and checklists

## Suggested Layout

```text
ai-team-python/
  profiles/
  skills/
  templates/
  policies/
  scripts/
```

## Integration

Use with `ai-team-core` as follows:

1. Keep orchestration and scoring in `ai-team-core`.
2. Load Python profile/skills from this repo per task.
3. Track stack-specific improvements here.
